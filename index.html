Recomendações do Mikrodomo

Por padrão, o Mikrodomo preserva a configuração original nestes pontos e nunca decide por conta própria. As opções abaixo são sugestões — só são aplicadas se você marcar a caixa. Acesso de gerência (SSH, Winbox, usuários e grupos) nunca é gerado ou alterado por esta tela, esteja marcado ou não: se o arquivo importado já tinha essas configurações, elas seguem intocadas em "Outras Configurações".
Desmarcado (padrão): reaproveita o nome original detectado no arquivo importado (ex: pppoe-out2), evitando criar uma interface duplicada.
Desmarcado (padrão): o Mikrodomo não inclui nenhum bloco /ip service na configuração gerada — o que já existia no arquivo original permanece do jeito que está, em "Outras Configurações". Se marcar esta opção e tiver importado um arquivo com configuração de acesso própria, edite/remova as linhas correspondentes em "Outras Configurações" para que este hardening realmente prevaleça (comandos executados depois sobrescrevem os anteriores no RouterOS).
